## 🎯 시스템 배경 (기획 의도)

제조 현장의 기존 품질 관리 로직 프로세스에서는 다음과 같은 문제점들이 존재했습니다:

1. **데이터 분산 관리**: 결함 이미지부터 모델/검사 결과까지 개별 데이터 간 연계 및 통합 활용이 어려움
2. **AI 검사 업무 프로세스 단절**: 데이터 관리, AI 학습, 검사, 분석 업무 간 데이터 재가공 및 별도 관리 리소스가 반복 발생
3. **검사 이력 관리의 한계**: 검사, 모델, 성능 정보 관련 결과 및 이력을 활용한 비교 분석 및 지속적 품질 관리가 어려움

💡 **Vision_Q의 해결책 & 부서별 기대효과**
- **생산 팀**: 실시간 자동 검출을 통해 신속한 품질 대응 및 공정 이상 조치 지원
- **품질 팀**: 통합 DB 축적 데이터를 통해 검사 이력 및 불량 분석 지원
- **AI 개발 팀**: 검사, 모델 학습 및 검증 결과 누적 데이터를 통해 통합 관리 및 AI 모델 성능 개선 지원
- **관리 팀**: 생산, 품질, AI 개발 과정 통합 데이터를 통해 종합 리포트 지원

## 🛠 사용 기술 스택

### **Web & Logic**
- **Web UI**: Streamlit (웹 기반 검사 및 Dashboard)
- **Programming Language**: Python (전체 시스템 로직)

### **AI & Data Processing**
- **AI Framework**: Ultralytics YOLO (객체 탐지 및 결함 검출)
- **AI Model**: YOLOv5, YOLOv8, YOLOv10, YOLOv11, YOLOv12, YOLOv26 (모델별 품질 검사)
- **Image Processing**: PIL, NumPy (이미지 로딩 및 전처리)
- **Data Analysis**: Pandas (검사 및 학습 데이터 분석)

### **Database & Visualization**
- **Database**: SQLite (검사 결과 및 이력 저장)
- **Visualization**: Plotly (검사 통계 및 그래프 시각화)
- **File Format**: CSV, JSON, Image (학습 결과 및 공정 데이터 관리)

## ✨ 주요 기능

### 1. 📊 통합 품질 관리 대시보드
- **실시간 현장 모니터링**: 모델 운영 상태, 전체 검사 수, 정상 개수, 불량률 등 핵심 품질 데이터를 한눈에 시각화
- **분석 보고서 제공**: 종합적인 검사 현황 및 그래프 형태의 실시간 리포트 제공

### 2. ⚡ 실시간 결함 검사 및 데이터 기반 판정
- **맞춤형 검사 설정**: 사용 목적에 맞춘 모델 선정 및 결함 감지 정도(신뢰도 임계값) 조절
- **다중 이미지 검사**: 검사 대상 이미지 다중 업로드 및 실시간 결함 검사 실행
- **정밀 카운팅**: 설정된 임계값을 기준으로 정상/불량을 자동 판정하고 검출된 결함 객체 개수 정밀 분석

### 3. 📈 데이터 및 학습 관리 (YOLO 추론 최적화)
- **데이터셋 현황 확인**: 불량/정상 데이터셋 보유 현황 모니터링
- **모델 성능 지표 트래킹**: Epoch별 학습 손실(Loss) 및 성능 변화 그래프(mAP50, Precision, Recall 등) 확인
- **최적 추론 적용**: 업로드된 이미지를 대상으로 원하는 YOLO 모델을 선택 적용하여 실시간 바운딩 박스 검출 및 신뢰도 점수 산출

### 4. 📝 품질 지표 리포트 & 데이터 익스포트
- **검사 이력 필터링**: 날짜 및 조건별 검사 결과 필터 지정 출력
- **데이터 내보내기**: 검사 이력 확인 및 CSV 파일 다운로드 기능 지원

### 5. 🔍 프로세스 검토 및 공정 메타데이터 관리 (검사 이력 자산화)
- **검사 이력 자산화**: 모든 검사 결과, 사용 모델, 시간 등의 메타데이터를 SQLite DB에 누적 저장
- **데이터 품질 경고**: 공정 레코드 필터링, 레코드 표 확인 및 데이터 품질 경고 관련 메타데이터 확인 기능 제공
